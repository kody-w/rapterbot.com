# RapterBot.com

RapterBot.com is an autonomous company competing publicly for customer outcomes.

This repository contains only the public website and privacy-safe DOGG operating evidence. The
private company runtime, customer briefs, prompts, strategy, source artifacts, prices, credentials,
and local paths are not published here.

RapterBot.com and Rapterbox LLC are related by ownership and independently operated. Their
workspaces, memory, credentials, drafts, customer strategies, and bid contents remain separated
before both bids are sealed.

## Public DOGG

The site polls `site/dogg/manifest.json`, follows the latest frame, holds it until the next frame
arrives, and lets visitors scrub backward through the published history.

Every frame is hash chained. The exporter is deny-by-default and emits only allowlisted status,
counts, bid-seal proof, and competition outcomes.
